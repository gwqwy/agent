模型

插件
插件目录需含 plugin.json 与 register.py。输入本地路径即可安装；点击条目右侧移除。
技能
技能即 SKILL.md（Agent Skills 通用格式）：模型按需加载全文。 插件自带的技能只读；安装到 profile 的技能可以移除。
市场
插件市场来自 awesome-dsh-plugin 社区精选目录（DeepSeek Harness 生态）。 安装即浅克隆仓库到当前 profile：原生格式（plugin.json + register.py）完整生效； dsh 的 npm/TS 插件只能识别其中的技能 / MCP / 配置等声明层，代码体无法执行，结果以插件列表为准。
