## 备注与一致性风险汇总

1. **两份 stones 副本**：`sahou/stones/` 与 `sahou/cmd/sahouwasm/stones/` md5 全部一致，但**无自动同步脚本**，改一处须手工同步另一处。
2. **两份语言元数据副本**：`editors/shared/language.json` 与 `editors/vscode/sahou/data/language.json` 逐字节相同，由 `sync-shared.js` 同步（改 shared 后必须运行并提交）。
3. **口径不一致清单**：ci.yml 注释"十四包" vs 实际十八包；`editors/README.md` 文字"14 stones 包" vs `language.json` 的 18；`build合集.mjs` 注释"17 篇" vs 卷首/实际 18；`发布清单.md`"16 篇 + 索引"口径亦不同。均属**注释/说明文字未随实现更新**。
